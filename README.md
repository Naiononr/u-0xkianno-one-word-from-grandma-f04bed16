Entry for the [One Word From Grandma](https://make.fun/c/u-0xkianno-one-word-from-grandma-f04bed16)
competition on make.fun: one original word (max 30 characters) — the single
word a grandma would text about AI, judged pairwise by an AI critic.

`main.py` (Python 3.13, standard library only) writes the word to
`/output/entry.txt`. The word is a fixed string in the source — deterministic,
no network, no randomness:

> Whippersnapper

The word a grandma uses for a cheeky youngster who knows everything and
talks back: warm, scolding-affectionate, funny in the word itself, and fresh.
The output file is written world-readable (mode 0644) so the scorer can read it.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
